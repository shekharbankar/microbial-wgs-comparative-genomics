PHASE 1 SUMMARY
Project: Comparative Genomics and Antimicrobial Resistance Gene Profiling of Escherichia coli

PROJECT STATUS
Phase 1: Project setup, reference genome acquisition, sequence composition analysis, and candidate genome metadata collection.
Phase 2: Will begin after the Phase 1 records are saved and reviewed.

1. PROJECT GOAL
The goal is to compare selected Escherichia coli genomes and investigate antimicrobial resistance (AMR) genes using reproducible bioinformatics workflows.

2. REFERENCE GENOME
Organism: Escherichia coli
Reference strain: K-12 MG1655

The first candidate set contains 10 records.
An additional query returned 20 records, including 10 candidates not present in the first set.
The combined reviewed candidate list therefore contains 20 unique candidates.

Candidate metadata includes assembly accessions, strain names, genome lengths, GC percentages, assembly levels, sequencing technology, and other available metadata.
Some fields are missing. Missing phenotype information must be treated as unknown, not as evidence of susceptibility.

6. CANDIDATE REVIEW AND DATASET SELECTION
The candidates vary in strain, sample source, collection date, and BioProject.
Six candidates in the initial set are associated with BioProject PRJNA238952.
The final 10-genome dataset has NOT yet been selected.
Final selection should consider assembly quality, strain diversity, metadata availability, and study independence where feasible.

7. PROTEIN-CODING GENE COUNTS
Protein-coding gene counts were collected from metadata for 20 candidate assemblies.
These counts have not yet been used to establish AMR status or resistance phenotype.

8. PLANNED PROJECT ANALYSES
- Finalize the candidate genome selection.
- Download the selected genome sequences.
- Compare genome length and GC percentage.
- Assess genome similarity and phylogenetic relationships using appropriate tools.
- Identify AMR genes using a suitable, documented tool and database.
- Interpret findings cautiously and distinguish detected genes from confirmed clinical resistance.

10. IMPORTANT LIMITATIONS
- The final comparison dataset is not yet finalized.
- AMR profiling has not yet been completed.
- No AMR phenotype should be inferred solely from a missing or unverified metadata field.
- Genome composition results do not establish genome quality, pathogenicity, or antimicrobial resistance.
- Only results that can be reproduced from saved files and scripts should be included in the final report.
